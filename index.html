Working with exercises

To load an exercise, type the exercise number into the exercise field and press load.
Some exercises provide some starting code! Be sure to load the exercise before you start working.
If you want to edit the board, or experiment, you should "Clear Exercise".
To see what your code is expected to do, click the green "Run & Grade" button at the top.


Debugging

Press Step from Start (top bar, or the "Debugging" tab) to pause on the first line of your code. While you debug, the step buttons sit in the top bar so the board stays in view.
Step Line (F10) runs your code one line at a time.
A green arrow marks the line that just ran, and a red arrow marks the next line to run.
Each function call gets its own box of variables. Values that just changed light up yellow.
Click next to a line number to add a breakpoint, then Continue (F5) skips ahead to it. Stop (Shift+F5) finishes the run without pausing.
Step Expression (F11) runs one piece of a line at a time and lists each value it computes, like arr[i] → 2.
Step Back (Shift+F10) goes back one step. Turn on Predict first to guess each new value before it's shown.
